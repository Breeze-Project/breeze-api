# ADR-0001: Проектирование API

**Статус:** Принято
**Дата:** 30/07/2026

## Контекст
Мы переписываем старое API на новое, более адекватное и отвечающим нашим требованиям.

## Результат
Перенос breeze-api в отдельный репозиторий и переписывание api с нуля, с референсами на прошлый, но под новые требования.

## Альтернативы
1. **Остаться на предыдущем API:** Отклонено из-за того, что оно создавалось в моменте и сбора требований не проводилось.

## Последствия:
* **Положительные:**
    * API не навайбкожено.
    * API будет соответствовать новым требованиям.
* **Отрицательные:**
    * Потребуется в будущем переписать все модули под новое API.
